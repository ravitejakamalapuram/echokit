# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| Latest (Chrome Web Store) | ✅ |
| Older versions | ❌ — please update |

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Email: **security@echokit.dev**

Include:
- A description of the vulnerability and its potential impact
- Steps to reproduce
- Any proof-of-concept code (if applicable)
- Your name / handle for acknowledgement (optional)

You will receive an acknowledgement within **48 hours** and a resolution timeline within **7 days**.

## Scope

In scope:
- Chrome extension source code (`extension/`)
- License validation worker (`worker/`)
- CLI server (`cli/`)

Out of scope:
- Social engineering attacks
- Issues in third-party dependencies that have no current exploit

## Disclosure policy

We follow coordinated disclosure. Once a fix is shipped, we will credit the reporter (if desired) in the release notes.
