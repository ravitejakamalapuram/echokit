Try a 10-second demo

See the whole record → mock loop on a free public test API before you point EchoKit at your own app. Keep this tab open as your checklist.

  1. In the demo tab, click the EchoKit toolbar icon and press ● REC.
  2. Make a couple of API calls: click Run script on the page, or paste this into the DevTools Console (Chrome may ask you to type allow pasting first):
    fetch('https://jsonplaceholder.typicode.com/todos/1').then(r => r.json()).then(console.log); fetch('https://jsonplaceholder.typicode.com/users/1').then(r => r.json()).then(console.log);
  3. Press STOP. You'll see GET /todos/1 and GET /users/1 in the list.
  4. Flip the MOCK switch on.
  5. Click /todos/1 and edit the response body, e.g. change "title" to "Mocked by EchoKit".
  6. Reload the demo tab and run the calls again. The response now shows your edit, served by EchoKit with no backend change.
The demo site is JSONPlaceholder, a free fake REST API. Nothing you record leaves your browser.
01 / RECORD
Capture real traffic
Open any tab. Click the EchoKit toolbar icon. Press ● REC. Use your app — every fetch and XHR call is captured.
02 / EDIT
Tune your mock
Tap any request. Edit the JSON body, change status, add latency, force errors. Pick a match mode (strict → wildcard → GraphQL).
03 / MOCK
Replay without the backend
Flip the master MOCK switch. Reload the page — your app hits the mocks, not the network. Big amber banner means you never forget.
