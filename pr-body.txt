🚨 Severity: HIGH
💡 Vulnerability: Several innerHTML assignments in layouts.js and app.js were lacking the required sanitizeHTML wrapper, introducing a DOM XSS vulnerability where dynamically generated HTML (like interaction lists and code highlights) is rendered.
🎯 Impact: An attacker could potentially inject malicious scripts that execute in the extension context via malformed interaction data or JSON payloads.
🔧 Fix: Wrapped missing innerHTML assignments in app.js and layouts.js with sanitizeHTML, and imported it where missing.
✅ Verification: Tested locally with 'pnpm test' and 'pnpm lint', verified innerHTML assignments across extension files using grep.
